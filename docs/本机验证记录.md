## ✅ 第二轮：她自己的通道 + 语气（2026-09-29 补测）

需求里说「要有这个鲸鱼娘的语气」，所以又做了一轮实测，中间挖出一个必须知道的坑。

### 坑：全局人设补丁会被 preset 遮蔽

只打 `system-prompt.personaPrefix` 补丁时，她的回答仍是通用口气
（「DeepSeek Harness 里的编码智能体…」）。查配置树发现 web profile 的 agent preset
里有 **4 个作用域内的 `- id: persona`（`@deepseek-ai/dsh-persona`）行**，
按 DSH 的规则「agent 作用域的同名贡献覆盖全局默认」——所以我们打在全局的那份被遮蔽了。

**解法**：把同一段人设再写进**桌宠自己的工作区** `~/dsh-deck-workspace/AGENTS.md`。
`dsh-agent-instructions` 会把「会话工作目录下的 AGENTS.md」当工作区指引注入每一轮，
走的是另一条通道，不受 preset 遮蔽；而且只影响她自己的会话，不碰 `~/.dsh/AGENTS.md`、
不影响主人其它会话。两份都写，双保险。

### 她自己的说话通道（比 headless 好得多）

上游插件自己暴露了两个路由，实测可用：

| 路由 | 实测结果 |
|---|---|
| `POST /dsh-pet/say` `{text}` | `{"ok":true,"sessionId":"…","created":true}` —— 内部走官方 `sessionController.prompt` |
| `GET /dsh-pet/events`（SSE） | 一次问答收到 `delta`×435、`assistant`、`tool-call`、`tool-draft`、`tool-result`、`turn-start/end`、`hud-turn` |
| `GET /dsh-pet/state` | `{ok,version,sessionId,status,turn,step,clients,hasSessionController}` |
| 鉴权 | 需要 `Cookie: dsh_pet_desk=<~/.dsh/dsh-live2d-pet-desktop.json 里的 token>`，不带就 401 |

> ⚠️ `/dsh-pet/say` 不传 `sessionId` 时会用「主会话」。在 Deck 上那就是她自己的会话（正确）；
> 但在已经有别的会话在跑的机器上测，先 `GET /dsh-pet/state` 看一眼 `sessionId` 是不是你要的那个，
> 别把测试消息打进主人的正经会话里。

### 语气验证实录

服务按插件的方式启动（`--profile web --patch persona.patch.yml --patch model.patch.yml
--no-open --port 3080`，cwd = `~/dsh-deck-workspace`），然后 POST 一句
「主人测试语气：用你的语气说一句话，报一下你是谁、在哪儿。」，她回：

> 哼，主人这是要考人家呀～
>
> 本鲸是「鲸鱼娘」，你的游戏大师，现在正舒舒服服地窝在主人的 Steam Deck 上呢。
> 桌宠位就是人家的地盘，别想赶人家走嘛 (๑•̀ㅂ•́)و
>
> ……不过话说回来，主人今天没带截图来？有卡关的地方就丢过来，人家帮你看攻略。
> 没有的话——人家要去吃白米了欸。

称呼「主人」✓ 自称「本鲸 / 人家」✓ 傲娇嘴甜 ✓ 贪吃白米 ✓ 颜文字 ✓ ——
和 `skill/SKILL.md` 里写的「称呼『主人』，自称『人家』/『本鲸』，傲娇嘴甜、聪明但懒、贪吃白米、不能被叫胖」完全对上。
而且这条回复是走**她自己的窗口**的：桌宠外壳里也会同步说出这句话、做表情。

## ✅ 第三轮：自动搜攻略 + 流式显示（2026-09-29 再做一轮）

这一轮把「她卡关就自己去搜」做实了，实测记录：

**输入**（模拟插件在 `auto_search: strong` 下拼的提问）：

```
主人卡关了：他在打《黑神话：悟空》第二章的黄风大圣，试了两个小时都过不去。
按这个顺序做，不要跳步：
1) 先说出你判断他卡在哪一步；
2) 用 web_search 至少搜一轮「黑神话 悟空 黄风大圣 打法」（当前版本优先）；
3) 最后只给最关键的 2-3 步做法，并用一句话说这条建议是从哪来的。
```

**她实际做的事**（从 `/dsh-pet/events` 里数出来的）：

| 事件 | 次数 | 说明 |
|---|---|---|
| `delta` | 538 | 流式输出正常，QAM 可以边收边长字 |
| `tool-call` | 3 | `web_search` → `web_fetch` → `web_fetch`（自己搜、自己翻页核实） |
| `assistant` | 3 | 分步发言，最后一条是完整建议 |
| `turn-end` | 1 | 一轮收尾 |

**她最后说的**（节选）：

> 人家先说猜的——主人十有八九**不是手残，是没拿到「定风珠」**……
> 以下是联网核实的（当前版本没改过这BOSS）：
> 1. **先去拿定风珠，别空手打。**……
> 2. **他一挥战戟起风，立刻按定风珠。**……
> 3. **开局先蓄两段重棍，见面直接招呼。**……
> 一句话来源：这三步是从九游那篇 [黑神话悟空黄风大圣打法](https://www.9game.cn/news/10639224.html) 里扒出来核实过的。
> 哼，主人下次带个截图来嘛，人家连你站在哪、血条剩多少都能给你看明白，比瞎猜强多了。

语气 ✓、先判断卡点再搜 ✓、搜完给 2-3 步 ✓、带来源 ✓、结尾撒娇 ✓ ——
这条链路就是插件里「截图并问她」走的同一条路（截图只是把相对路径写进提问第一行）。

**这一轮同时改掉的**：

* 截图不再放插件 runtime，直接落进她会话的工作区 `~/dsh-deck-workspace/screenshots/`，
  提问里用**相对路径**（她的 cwd 就是那儿），模型定位更稳
* `auto_search`：`strong`（默认，强制先搜再答+带来源）/ `normal` / `off`
* 流式事件 `dsh_deck_pet/stream` + 工具活动 `dsh_deck_pet/activity`
  （`web_search` → 面板显示「💭 在搜攻略…」）
* 兜底通道、`ask_channel` 切换、`reply_timeout` 都保留

### 还没做的：走 typert 网关直发 ImageBlock

官方文档写着附件是**客户端侧**归一化后以 `ImageBlock` + `ImageAttachmentRef` 进消息的，
`/dsh-pet/say` 只收纯文本。要让截图以真正的附件进消息，得走 DSH 的 typert 网关
（`connection.fetch` / remote 方法那套 WS 协议）。
目前用「工作区相对路径 + 她自己去读」已经能看图（第一轮实测过），
所以这条留作后续增强，收益是更稳、并且不依赖她愿意调 read 工具。

## ⏳ 只能上 Deck 验（插件里都写了降级路径）

| 项 | 为什么本机验不了 | 降级/兜底 |
|---|---|---|
| QAM 里 iframe 载入 `127.0.0.1:3080` | 依赖 Steam CEF 的 CSP | 用悬浮窗看，或 Desktop Mode 浏览器打开 |
| Game Mode 下悬浮窗盖在游戏上 | 依赖 gamescope 合成 | 切 Desktop Mode；或在 QAM 里用完整界面 |
| Game Mode 自动截图 | `grim`/门户依赖合成器 | `Steam + R1` 截图 + 目录监听兜底 |
| 录音与转写 | 需要 PipeWire 麦克风 | `parecord`/`arecord` 兜底；ASR 可换成任意 OpenAI 兼容服务 |
| Electron 在 SteamOS 上起窗 | `chrome-sandbox` 权限 | 已默认加 `--no-sandbox`，并写 `overlay.log` |

## 复现命令（在这台机器上）

```powershell
# 前端
cd dsh-deck-pet; pnpm install; pnpm run build

# 人设 + 模型补丁是否生效
dsh --profile web --patch out/verify/persona.patch.yml --patch out/verify/model.patch.yml --dump-config

# 一次性问答（真调模型）
dsh --profile headless --patch out/verify/persona.patch.yml --patch out/verify/model.patch.yml "用一句中文介绍你自己"

# 截图问答（把路径换成你自己的截图）
dsh --profile headless --patch out/verify/persona.patch.yml --patch out/verify/model.patch.yml `
  "[主人发来一张游戏截图：C:\path\shot.png] 先读图再回答：我卡在哪一步？"
```

> 注：本机 DSH 版本是 `0.2.0-rc.1`（CLI 里 `--profile headless` 是独立 profile，跑完即退出，
> 所以插件里的「直接问她」是无记忆的一次性问答；要连续对话就用桌宠页面本身）。
