# 安装与使用（Steam Deck）

## 0. 前提

* SteamOS 3.x（LCD / OLED 都行），能联网
* 已安装 [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader)
* 在 Decky 设置里打开 **Developer Mode**（否则看不到「从 ZIP / URL 安装插件」两个入口）
* 磁盘空间：首次会下载 Node（~50 MB）+ dsh 依赖（~300 MB）+ Electron（~100 MB），建议留 2 GB

## 1. 装插件

三种方式任选：

| 方式 | 做法 |
|---|---|
| ZIP（推荐） | 把 `out/dsh-deck-pet.zip` 拷到 Deck（U 盘 / `scp` / KDE Connect），Decky → 设置 → **Install Plugin from ZIP file** |
| URL | 把 zip 传到任意直链，Decky → 设置 → **Install Plugin from URL** |
| 手动 | 解压成 `~/homebrew/plugins/dsh-deck-pet/`，然后 `sudo systemctl restart plugin_loader` |

> 注意：zip 里只有一个同名顶层目录 `dsh-deck-pet/`，别把 zip 原样丢进 plugins 目录。

## 2. 第一次运行（QAM 里四步）

按 ⚙️/⋯ 打开快速访问菜单（QAM），找到「DSH 鲸鱼娘桌宠」：

1. **① 安装运行时** —— 下载 Node v24.18.1 到插件 runtime 目录，再用它装 `@deepseek-ai/dsh@next` 和 `pnpm`。
   全程不需要 root，也不动系统目录。
2. **② 安装鲸鱼娘插件到 web profile** —— 等价于在 Deck 上跑
   `dsh plugin --profile web add github:Andersen216/dsh-whale-girl-live2d`，
   把桌宠装进 DSH 的 `web` profile（这正是桌宠页面 `/dsh-pet/standalone` 的来源）。
3. **③ 启动 DSH 服务** —— 起 `dsh --profile web --no-open --port 3080`，并自动加上两份补丁：
   `persona.patch.yml`（游戏大士人设）和 `model.patch.yml`（你选的模型）。
4. **④ 让桌宠悬浮在屏幕上** —— 第一次会下 Electron，然后开一个 520×520 的透明置顶窗（默认缩放 0.7）。
   鼠标不在她身上时窗口点击穿透，不会挡住游戏操作。

服务起来后，QAM 顶部状态会变成 `DSH 服务 ✅ 运行中 :3080`。

## 3. 截图问攻略

两种用法：

* **插件帮你截**：点「📸 截图并问她」。后端依次尝试
  `grim` → `spectacle -b -n` → `gnome-screenshot` → ImageMagick `import` → `org.freedesktop.portal.Screenshot`。
  Desktop Mode 下通常第一条就成。
* **Game Mode 兜底**：如果上面的都失败（Game Mode 的合成器不给权限），按 **Steam + R1** 让 Steam 自己截图，
  再回插件点一次「截图并问她」——后端会发现 Steam 截图目录里多了一张新图并拿它去问。

在输入框里可以写想问什么（例如「这个 BOSS 怎么打」「这任务下一步去哪」），留空就用默认问法。
她的回答会显示在「她刚说」区块里。

## 4. 语音提问

1. 设置页里选转写方式：`OpenAI 兼容 /audio/transcriptions`（默认）、`交给 DSH 的语音插件`、或关闭
   * OpenAI 兼容：填 `ASR Base`（如 `https://api.openai.com/v1`）、`ASR Key`、语言（`zh`/`en`/`auto`）
2. QAM 里点「🎙 按住我说话」开始录音（底层用 `pw-record`，没有就退到 `parecord`/`arecord`）
3. 再点一次「⏹ 停止并发送」→ 转写 → 转写文本会作为提问发给她，同时显示在「你说」里

## 5. 换大模型 API

设置页 → 「大模型 API」：

| 场景 | 怎么填 |
|---|---|
| DeepSeek 官方账号（网页登录态） | Provider 选 `deepseek-official`，模型名 `deepseek-flash`，不用填 key |
| 自己的 DeepSeek API Key | Provider 选 `deepseek-api-key`，把 key 填进 API Key |
| 任何 OpenAI 兼容服务（自建 / 中转 / 别的厂商） | Provider 选 `自定义 OpenAI 兼容`，填 API Base + 模型名 + API Key |

保存后插件会把 key 写进 `~/.dsh/.credentials.yaml`（权限 600，只在本机），
把 provider/模型写进 `model.patch.yml`，然后你重启一次 DSH 服务即可生效。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 插件图标不出现 | `~/homebrew/services/PluginLoader/PluginLoader.log` 看 traceback |
| 后端日志 | Decky 设置 → Developer → Plugin Logs → 选本插件；或 `~/homebrew/logs/dsh-deck-pet/*.log` |
| 服务起不来 | 看 `<插件runtime>/dsh-web.log`；端口被占就把设置里的端口改掉（但桌宠外壳写死了 3080） |
| 悬浮窗全黑/不透明 | Desktop Mode 里确认 KDE 合成开着；`<插件runtime>/overlay.log` 里常有线索；也可以先不关 sandbox 开关重试 |
| 游戏里看不到她 | Game Mode 靠 gamescope 合成第三方窗口，个别游戏（全屏独占/Vulkan 直通）可能盖不住，切 Desktop Mode 或改用 QAM 里的完整界面 |
| 截图一直是提示卡片 | 说明四种自动截图都没成：装 `grim`（Desktop Mode）或改用 Steam + R1 兜底 |
| 语音没反应 | `wpctl status` 看麦克风；确认录音工具存在；ASR Base/Key 是否正确 |

## 7. 卸载

1. Decky 里卸载插件（会调 `_uninstall`）
2. 想彻底清干净，手动删：`~/homebrew/plugins/dsh-deck-pet/`、`~/homebrew/settings/dsh-deck-pet/`、
   以及插件 runtime（含 Node 和 Electron）；DSH 自己的数据在 `~/.dsh/` 和 `~/dsh-deck-workspace/`
3. 不想留桌宠：`dsh plugin --profile web remove dsh-whale-girl-live2d`
